# v0.0.3 — saved credentials and local mirror ignores

Release notes prepared for the `net-work-studio/figmog` fork. This release
has not been tagged or published.

## Changes since v0.0.2

- Save a Figma personal access token with `figmog auth login`, inspect its
  configured source with `figmog auth status`, and remove it with
  `figmog auth logout`. Tokens live in macOS Keychain or Linux Secret
  Service and are shared across projects, terminals, and Git worktrees.
- Read tokens from a hidden terminal prompt or pipe them to
  `figmog auth login --token-stdin`. Tokens are not accepted as command-line
  arguments or written to project files, and status output never reveals
  them.
- Keep using `FIGMA_TOKEN` for CI or account overrides. An explicitly empty
  value disables saved credentials for offline use. Logout removes only
  the saved token; it leaves an environment override active.
- After a successful `figmog pull` into the default `.figmog/` directory
  inside a Git repository, add an ignore rule if needed. Existing rules
  and Git worktree boundaries are respected. Custom `--db` locations are
  left unchanged; an ignore-update failure warns without failing the pull.
- Point README downloads and source-clone instructions to
  [net-work-studio/figmog](https://github.com/net-work-studio/figmog).
- Refresh the README banner and explain Figma's API caching guidance.

## Upgrading

Existing v0.0.2 mirrors remain compatible; no mirror rebuild is required.
Environment-based authentication continues to work. To switch to saved
credentials, unset `FIGMA_TOKEN`, run `figmog auth login`, and restart any
running MCP server. Login saves the token without validating it against
Figma; replace expired or revoked tokens by logging in again.

Linux saved credentials need a running, unlocked Secret Service such as
GNOME Keyring or KWallet. Headless environments can continue using
`FIGMA_TOKEN`.

Commit any new `.figmog/` ignore rule. Ignore rules do not untrack mirrors
already committed to Git, and mirror data is local to each worktree.

## Installation and release status

Once published, testing tarballs and `SHA256SUMS` will be available on the
[fork's releases page](https://github.com/net-work-studio/figmog/releases)
for `aarch64-apple-darwin`, `x86_64-apple-darwin`, and
`x86_64-unknown-linux-gnu`. See the [README installation instructions](../../README.md#install)
for checksum verification, macOS quarantine removal, and the Linux glibc
requirement.

figmog remains AGPL-3.0-only. The pinned `fold` dependency comes from
`bogkit`, which currently has no license file; broader binary
redistribution remains deferred as described in the
[README license section](../../README.md#license).
